# Accountability & Focus Rooms

A full-stack application for joining and creating focus rooms, connecting with friends, and tracking your progress together with accountability partners.

## What it does

This project is an accountability and focus room application. Users can:
*   **Join or create focus rooms** to work together.
*   **Connect with friends** and see what they are up to.
*   **Track progress** and nudge your accountability partners.

## Tools Used

*   **Frontend:** [Preact](https://preactjs.com/) built with [Vite](https://vitejs.dev/) and styled using [Tailwind CSS](https://tailwindcss.com/).
*   **Backend:** [Firebase Cloud Functions](https://firebase.google.com/docs/functions) running an Express REST API.
*   **Database:** [Cloud Firestore](https://firebase.google.com/docs/firestore) for storing rooms, sessions, tasks, and users.
*   **Authentication:** [Firebase Authentication](https://firebase.google.com/docs/auth) with Google Login.
*   **Local Development:** Configured with Docker for environment consistency and Firebase Emulators for testing cloud services locally.
